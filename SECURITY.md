# Security Policy

Mnemosyne is currently in the concept/foundation stage and has no executable implementation yet.

When implementation begins, security-sensitive areas will include:

- Download URL validation
- Path traversal prevention
- Filename sanitization
- Temporary/staging file handling
- Archive extraction safety
- Provider authentication/token storage
- Checksum verification
- Update/dependency integrity
- Protection against destructive overwrite

Security issues should be reported privately to the repository maintainer rather than disclosed publicly before a fix is available.
